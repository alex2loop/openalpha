# Research scoping

Use before calling `research` on an instrument, a sector, or a policy question. The pipeline that answers is domain-blind: it reads the query text, a depth and a locale, and knows nothing about the market, the instrument, or the book. The query is the only place domain knowledge can enter, and the run is charged whether or not it was aimed well.

## Never ask for the decision

The planner refuses to turn a request into a recommendation, a verdict, or a conclusion-seeking question. "Should I buy this" spends a run having the request quietly reframed into something answerable. Ask for the evidence a decision needs and take the decision here, where the book, the caps and the levels are.

## One question per independent evidence direction

The request is split into questions that can each be searched without waiting on a sibling's answer, up to a configured maximum, so what the query names is what gets asked:

- A time-sensitive buy, sell or hold ordinarily splits into current state and trend, drivers and outlook, and the market constraints that bind. Naming the third is what stops the run spending itself on the first two.
- Naming one direction is how to spend the whole budget on one thing. A request that narrows stays narrow.

## Ask for what no source here carries

Prices, factors, levels and the numbers derived from them are already in the deterministic path, and asking research to restate one buys a citation for something not in doubt. Research earns its cost on what that path has no source for:

- Governance: the controlling shareholder, insider pledges, related-party revenue and receivables.
- Corporate actions and their legal status, which no factor can see.
- A token's supply overhang: unlock schedule, treasury sales, miner distribution.
- Policy: the import quota that sets the domestic gold premium, a foreign ownership rule change, a credit growth target.

## Name the source, not the topic

Each question carries a preferred source kind from `primary`, `official`, `filing`, `peer_reviewed`, `reporting`, `secondary`, so a query that names the document reaches it. The authority order the analysis skills already teach maps onto those: an audited annual report or a quarterly is a `filing`, an exchange disclosure or regulator notice is `official`, a wire story is `reporting`, and a sell-side note is `secondary` - a source of questions, never of conclusions.

A figure survives only where one source states its value, unit and date together, so ask for the dated number rather than the claim about it. Provider summaries and search highlights are discovery material and never evidence, which is why a query aimed at a headline returns less than one aimed at the document beneath it.

## Depth

`quick`, `standard`, `thorough`. `quick` is not adjudicated by the reviewer at all, so its claims were never checked back against their sources: read it for orientation, never as support for a thesis.
