# VN daily buy

Use when screening the VN universe for something to buy today. The morning routine. Its purpose is to make most days produce nothing, which is the correct output on most days.

## Order of work

1. **Regime first.** Read the macro regime and index context. A risk-off regime lowers deployable capital before any name is considered; it never raises it.
2. **Screen the universe.** Rank by the market's factor model, then read the universe size and the freshness caveats before trusting a rank.
3. **Apply hard gates.** Drop anything that fails a mechanical gate: not tradeable, at a band, foreign room exhausted, insufficient liquidity for a normal position, or on the profile's exclusion list. These are not judgement calls.
4. **Quality and valuation.** Run the quality screen on the survivors, then valuation against the name's own history. A cheap failing business is not a candidate.
5. **Portfolio fit.** Reserve, position cap, segment cap, sector cap, then any driver shared with a holding in another sector. Most survivors die here, and that is the system working.
6. **Structure and levels.** Only now does price structure matter: where the idea is invalidated. The pipeline sets the levels by rule and marks a plan void once the price leaves them, so the risk-reward it prints comes from the same rule on every buy: never rank or drop a name on it.

## The bar

A candidate must have: a stated driver, a dated fact supporting it, a level that invalidates it, and room in the book. Missing any one makes it a watch item, not a buy.

## Discipline notes

- Cooldown exists so the same name is not re-suggested daily on noise. A name inside its cooldown is not a new idea.
- An empty result is a valid morning. Manufacturing a candidate to fill the brief is the single most expensive habit this routine prevents.
- Do not raise size because yesterday's suggestion worked.

## Output

Either a short ranked list where each line carries driver, invalidation, and cap headroom, or an explicit statement that nothing cleared the bar today and why.
