# Behavioral finance

Use when an argument feels stronger than its evidence, or when the operator is about to act shortly after a gain, a loss, or a headline.

## The biases that actually cost money here

| Bias | How it shows up in this product | The disproving check |
| --- | --- | --- |
| Anchoring | The thesis leans on the 52-week high, the IPO price, or the operator's entry | Restate the case using only the last two quarters. Does it survive? |
| Confirmation | Every cited source argues one direction | Name the strongest source that disagrees. If none was read, the case is untested. |
| Recency | A three-session move is treated as a regime | Compare the move against the trailing year's distribution. |
| Loss aversion | "Wait for breakeven" appears in the reasoning | The entry price is not information. Would you open this position today at this price? |
| Disposition | Winners trimmed early, losers held | Check the ledger: are realized holding periods shorter for gains than losses? |
| Overconfidence after a win | Size creeps up after a run of correct calls | Read the track record's calibration buckets, not the last three outcomes. |
| Narrative | The claim is a story about the company, not a number | Ask which line of the financials would move if the story were true. |

## How to apply it

1. State the bias by name and quote the exact sentence that carries it.
2. Give the check that would disprove it - a specific comparison, not "be careful".
3. If the check cannot be run with the supplied evidence, say the claim is untested rather than unsupported. They are different failures.

Do not use this skill to soften a conclusion. A well-evidenced case that happens to be popular is not "herding"; naming a bias without the disproving check is itself a rhetorical move.

## Reading the operator's own record

`suggestion_track_record` reports win rate by conviction band. A high-conviction bucket that underperforms the medium bucket is overconfidence with a number attached, and it is more useful than any single trade's post-mortem.
